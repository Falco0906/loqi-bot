# Philosophy

Loqi is designed around a simple principle:

> Everyone gets the same core intelligence.
> Higher plans increase scale, automation, collaboration,
> and operational capability.

We intentionally avoid feature fragmentation where possible.

Customers should upgrade because they are growing,
not because essential functionality has been artificially removed.

# Discovery Credits

Discovery Credits represent external provider costs.

Credits are consumed only when an action successfully returns usable data.

No result:

→ No credits consumed.

Cache hit:

→ No credits consumed.

Users can always view remaining credits.

Example:

1,250 Discovery Credits Remaining

≈ Enough for ~900 verified prospects

Discovery Credits may roll over for one billing cycle.

# AI Usage

AI usage follows a Fair Use model.

Plans are intentionally generous for legitimate business usage.

Loqi reserves the right to rate-limit abusive or automated exploitation.

Typical users should never encounter AI limits during normal usage.
